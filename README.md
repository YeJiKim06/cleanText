# 🛡️ AI 숨겨진 워터마크 클리너 (AI Hidden Watermark Cleaner)

> **텍스트 내에 삽입된 보이지 않는 유니코드 문자(Zero-Width Characters 등)를 실시간으로 탐지하고 정제해 주는 보안 도구입니다.**

LLM(대형 언어 모델) 생성 텍스트나 보안 문서에는 추적 및 출처 식별을 위해 눈에 보이지 않는 특수 유니코드 문자가 워터마크 형태로 삽입될 수 있습니다. 본 도구는 이러한 숨겨진 워터마크 문자들을 유형별로 실시간 추적하고 단 한 번의 클릭으로 완벽하게 제거하여 순수한 텍스트 데이터만 남겨줍니다.

---

## ✨ 주요 기능 (Key Features)

* **실시간 워터마크 탐지:** 텍스트를 입력하는 즉시 5가지 카테고리의 비가시성 특수 문자를 정밀 분석하여 개수를 화면에 표시합니다.
* **5대 주요 추적 문자 정제:**
    * **제로 너비 문자 (U+200B ~ U+200F):** 공백처럼 보이지만 너비가 없는 문자
    * **단어 결합자 (U+2060 ~ U+2064):** 줄바꿈을 방지하는 투명 기호
    * **변형 선택자 (U+FE00 ~ U+FE0F):** 글꼴 스타일 변형용 제어 문자
    * **양방향 텍스트 제어 (U+202A ~ U+202E):** 텍스트의 좌우 쓰기 방향을 바꾸는 제어 문자
    * **결합 발음 구별 기호 (U+0300 ~ U+036F):** 다른 문자에 겹쳐서 표시되는 특수 기호
* **원클릭 클린 업:** '워터마크 제거 실행' 버튼으로 가시적인 일반 공백 및 텍스트 구조를 해치지 않고 추적용 문자만 선별 제거합니다.
* **사용자 친화적 UX:** 정제된 결과를 다크 모드 스타일의 코드 블록으로 가독성 있게 보여주며, 복사 및 개별 창 초기화 기능을 제공합니다.
* **반응형 레이아웃:** 그리드(Grid) 시스템을 적용하여 데스크톱과 모바일 화면 모두 최적화된 UI를 제공합니다.

---

## 🛠️ 기술 스택 (Tech Stack)

* **Front-end:** HTML5, CSS3 (Grid & Flexbox 레이아웃, 미디어 쿼리 기반 반응형 웹 디자인)
* **Script:** Vanilla JavaScript (유니코드 정규 표현식 매칭 엔진, Clipboard API)
